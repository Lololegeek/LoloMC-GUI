# LoloMC GUI — NeoForge example

This example opens the shared XML/CSS demo with the **O** key on NeoForge 1.21.1.

The NeoForge wrapper uses Mojang mappings and shares the same runtime, XML, CSS, and `MinecraftScreenHost` as Fabric and Forge.

```powershell
gradlew.bat build
gradlew.bat runClient
```
