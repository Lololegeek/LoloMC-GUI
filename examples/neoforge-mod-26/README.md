# NeoForge 26.x example

Minecraft 26.1 and newer are unobfuscated and require Java 25. This profile uses NeoForge's ModDevGradle toolchain and the extracted GUI rendering pipeline, separately from NeoGradle and the pre-26 screen adapter.

Build one exact release with `./gradlew build -Pminecraft_version=26.2 -Pneoforge_version=26.2.0.88`.
