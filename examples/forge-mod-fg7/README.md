# ForgeGradle 7 example

This example profile covers Forge 1.21.3 and newer, where Forge's development toolchain uses ForgeGradle 7. Older Forge releases remain on the ForgeGradle 6 profile in `../forge-mod`.

Run `./gradlew build -Pminecraft_version=1.21.11 -Pforge_version=61.2.1 -Pjava_version=21` to build the client example for one exact Forge release.
