# Forge 26.x example

Minecraft 26.x uses Java 25 and unobfuscated game classes. This profile uses ForgeGradle 7 and the current GUI extraction API; it is separate from both the ForgeGradle 6 and pre-26 Forge examples.

Build one exact release with `./gradlew build -Pminecraft_version=26.2 -Pforge_version=65.1.3`.
