# Fabric 26.x example

Minecraft 26.1 and newer are unobfuscated and require Java 25. This profile uses Fabric Loom's non-remapping plugin ID and Mojang's published class names; it is intentionally separate from the Yarn-mapped 1.20–1.21 example.

Build an exact release with `./gradlew build -Pminecraft_version=26.2 -Pfabric_version=0.161.0+26.2`.
