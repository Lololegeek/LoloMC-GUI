# LoloMC GUI 0.1.0

LoloMC GUI is a loader-neutral Minecraft GUI library for polished XML + CSS in-game screens.

## Included

- Java 8-compatible runtime for XML, CSS, responsive layout, state, and input handling.
- Explicit rendering adapter contract for Minecraft version families.
- LoloMC GUI Studio with live preview, drag positioning, XML/CSS editing, undo/redo, import, and export.
- Runnable Fabric 1.21.1, Forge 1.20.1, and NeoForge 1.21.1 example mods.
- Server-selector example and integration documentation.

This is the first public release. The APIs are intentionally small and experimental; contributions and feedback are welcome.
